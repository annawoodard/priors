# Answer a question about the literature

1. Read `index.md`. Open the map and topic pages whose summaries fit, then the
   paper notes. Grep any level directly if you already know what you want.
2. Answer with links to the notes you used, and quote the paper where it
   matters. Keep what papers show apart from what they speculate and from
   your own inference.
3. Say plainly when the library doesn't cover the question, and offer to
   search outside (`priors lookup`) or run mentor mode.
4. If the owner wants the answer kept, save it as a topic page and rebuild the
   index. Log the question.

From another repo, set `PRIORS_LIBRARY` to the library's path so commands
find it. Running `priors where` inside the library prints the path.
