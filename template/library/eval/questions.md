# Evaluation questions

Questions an agent should be able to answer from this library, with the notes
a complete answer must cite. Run them with the engine's
`procedures/evaluate.md`; results go in `eval/runs/<date>.md`.

Types: `find` (locate a paper), `compare` (across papers), `known` (what the
library says about X), `contradicts` (evidence against a claim), `transfer`
(an idea from another area applied to the owner's domain), `trace` (follow a
claim to its quote), `abstain` (the library doesn't cover it). Mark questions
that word an idea differently from the papers as `paraphrase` in Tests.
